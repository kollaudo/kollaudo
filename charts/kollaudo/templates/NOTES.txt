  kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "kollaudo.fullname" . }} -- kollaudo-server project create <name>

{{- if .Values.ingress.enabled }}

{{- else }}

Then reach the API and the UI, for example with:

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "kollaudo.fullname" . }} 8080:{{ .Values.service.port }}
{{- end }}

CI jobs send results with KOLLAUDO_URL and an ingest token: see
